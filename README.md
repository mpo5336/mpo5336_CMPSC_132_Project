# mpo5336_CMPSC_132_Project
This project is a number guessing game that I designed for my CMPSC 132 class.
In this game you will guess a number that is between 1 and 100. In order to play 
this game you will need to download the Matt_Owen_Project.py file and then open it in 
an interactive shell. From there the program will ask you to choose a difficulty. Which
can be 1. Easy (15 attempts), 2. Medium (10 attempts), or 3. Hard (5 attempts). To select
a difficulty you must enter the respective integer that goes along with the difficulty you
would like to select. Now you can start guessing numbers and the game will tell you if
you need to choose a number that is higher or lower. Once you run out of attempts or guess
the number correctly it will ask if you would like to play again. You can choose either y (yes)
or n (no).
